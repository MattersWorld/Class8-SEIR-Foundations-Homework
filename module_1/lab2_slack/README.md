# Lab2_slack

In this lab I built a secure, severity-filtered path for operational alerts to travel from Python on EC2 into Slack.

One specific  AWS concept that was imperative to the lab was creating and properly labeling AMIs. Each class we make an AMI in which we will launch and add onto the progress. This is essentially versioning as the saved AMI can allow us to go back to previous environments.

New commands I learned from the lab:
nano - opens text editor, similar to vi command /n
cp- it is a copy command that does not edit the original file
