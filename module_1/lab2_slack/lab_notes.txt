# Lesson2_Slack Homework notes


Create instance from a template. Choose the most recent AMI or whatever AMI that was used up to the point of the assignment.
When you use you own AMI, you are defaulted as the root user. We installed the directories on the ec2-user profile so you to cd back to the parent directory. (cd ..)
Once you're there use ls to see what directories are there. You want to see "home". Cd into the home directory, and the into the ec2-user directory. From there you can access the SEIR-Foundations repo.

Follow the directions given and make sure you do each command one at a time. Verify that the outputs match and proceed.


When you use nano, you cannot use the mouse, only the keyboard. To exit use ctrl+O, enter, ctrl+X. 

When you try to run the first homework py file, it will tell you to nano into it and add your name. 

For py file 4, the program gives a snapshot of how much of the storage is being used. The severity level is programmed based on how much space is remaining. Its good design for the output to be INFO severity because there is no issue or impending changes needed to be made. At 25% usage, it is simply a status update and not worth a real warning.

```
(venv) [root@ip-172-31-18-165 balerica-bank]# python hw4_disk_watch.py
Disk is 25.3% used -> severity INFO.
Delivered!
```
