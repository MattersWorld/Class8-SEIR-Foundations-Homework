Paragraph (minimum 5 sentences): 
A database is an organized collection of information. It can operate as a form of long term memory for an app. For applications where you can login as a user, an application can store data such as your alias, passwords, and other data that can be useful. The major types of databases are SQL and NoSQL. Within those categories you'll find relational databases, key pair, document databases, and graph databases. We choose one database over the other based on what the application requires. If the data is more flexible and unpredictable, you may consider using a non-relational database. On the other hand, a more structured data set that is to be used for analytics may be a better choice for a relational database. SQL is a relational database and NoSQL is a non relational database that uses different models to manage data. In the cloud AWS has Amazon RDS, Amazon Aurora, DynamoDB, Neptune, DocumentDB, and other database services. The de facto databases of the industry are Oracle, MySQL, MicrosoftSQL Server and PostgreSQL. The reason a  bank would not use SQL lite is because a large bank would be handling a large amount of workload and would benefit from the aspects that PostgreSQL or a SQL server provides. SQL lite is not unprofessional by any means, but it might not provide enough support for the mass amount of managers and users accessing the platform simultaneously.

Paragraph (minimum 5 sentences):
COBOL is a compiled computer programming language designed for business use. It was introduced by CODASYL. It was first integrated on mainframes  to automate tasks. There is not an exact count of how many systems use COBOL today, but an estimate by one source says nearly 800 billion lines of code is running on production systems and daily use. Many replacement projects have struggled because of reasons such as mass layoffs and retirement of the programmers who actually know how to use the system. These reasons also cause the system to continue to be used at a higher volume. Using an implied decimal point actually saved storage space that decimals could use up.
